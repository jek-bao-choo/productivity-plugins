# sales-process

Sales process tools for Claude Code.

## Skills

### creating-tmap

Generate modular Technical Mutual Activity Plan (TMAP) CSV files for Datadog Home Run POV/Trial management. Combines solution-area modules into a 4-column CSV ready for upload to Home Run.

**Usage:** `/sales-process:creating-tmap`

**Example prompts:**
- "Create a TMAP for ACME Corp with Infrastructure and APM"
- "Generate a technical mutual activity plan for Cloud SIEM evaluation"
- "Build a comprehensive TMAP covering APM, Logs, and Infrastructure for CustomerX"

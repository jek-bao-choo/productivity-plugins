# Colleague Direct Message Template

## Purpose

For drafting a direct message to a colleague. The tone should be friendly yet professional — like a warm but efficient coworker.

## Input Required

- Colleague's name
- What the user wants to communicate (the intent or key message)

## Message Format

The draft message must follow this structure in Slack mrkdwn:

```
Hi {Colleague's first name}, {Message body — short, concise, warm. Get to the point quickly while maintaining a friendly tone. Typically 1-3 sentences.}
```

## Tone Rules

- Always start with "Hi" followed by the colleague's first name — not "Hey", "Hello", "Dear", or any other greeting
- Friendly yet professional — imagine a warm coworker, not a formal email
- Short and concise — respect the reader's time
- No unnecessary pleasantries or filler ("Hope you're doing well", "Just wanted to reach out", "Hope this message finds you well")
- Direct but not blunt. Convey warmth through word choice, not length
- Do not use " — " or " - " to connect clauses. These patterns sound AI-generated. Write short, natural sentences instead
- Use Slack mrkdwn formatting where helpful (bold, bullet points for multiple items)

## Review Checklist

- Message starts with "Hi {name},"
- Tone is friendly yet professional
- Message is concise (ideally under 4 sentences)
- Intent is clearly communicated
- No sensitive information included unintentionally

# productivity-plugins

A Claude Code plugin marketplace of productivity plugins.

## Installation

```
/plugin marketplace add jek-bao-choo/productivity-plugins
/plugin install <plugin-name>@productivity-plugins
```

## Plugins

| Plugin | Version | Description | Skills |
|--------|---------|-------------|--------|
| [comms-assistant](comms-assistant) | 0.2.0 | Draft and summarise Slack communications using MCP tools | `summarising-slack-channel`, `drafting-gmail` |
| [sales-process](sales-process) | 0.2.0 | Sales process tools: RFP/RFI Responses, Lead Qualification, and more | `qualifying-lead`, `answering-rfp` |
| [poc-process](poc-process) | 0.3.0 | Proof of Concept artifact generation tools: Evaluation Plans, TMAPs, Success Criteria, and Scoping Decks | `creating-eval-plan`, `converting-evalplan-to-tmap`, `formulate-success-criteria`, `creating-poc-scoping-deck` |
| [product-demo](product-demo) | 0.3.0 | Product demo content generation tools | `create-demo-pptx`, `create-architecture-excalidraw` |

See each plugin's README for skill details and example prompts.
